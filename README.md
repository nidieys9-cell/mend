mend applies AI-written patches in four formats — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edits — to a tree of text files, matching each edit at the first of three tiers and writing every change or none. `SPEC.md` is the whole contract.

## Run it

```sh
node main.ts patch.diff
```
